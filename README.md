# ChangeReview-docs (moved)

The ChangeReview documentation now lives in
[Genuitec/eclipse-ai-tools](https://github.com/Genuitec/eclipse-ai-tools) and is
published at https://genuitec.github.io/eclipse-ai-tools/, together with the
Inline Diff for Eclipse documentation.

This repository stays online only so that old links keep working: its GitHub
Pages site serves small pages that redirect each old URL to the matching page on
the new site. Do not delete or rename this repository while released plug-ins or
listings still link to https://genuitec.github.io/ChangeReview-docs/.

To change where an old URL points, edit `REDIRECTS` in
`tools/make_redirects.py`; the workflow regenerates the pages on push.
