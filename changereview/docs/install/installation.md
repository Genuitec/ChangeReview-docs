# Installation

Install ChangeReview from Eclipse Marketplace, then restart Eclipse.

## 1.0 Early Access 1

ChangeReview 1.0 Early Access 1 is usable for **45 days from installation**.
To continue using ChangeReview after that period, install a newer release.
The production release is expected in **November 2026**.

Please test drive ChangeReview and share feedback or report issues on the
[Support Forum](https://github.com/Genuitec/ChangeReview-community/discussions).

## Prerequisites

- An Eclipse IDE or Eclipse-based product supported by ChangeReview.
- Windows 11 or 10, macOS, or Linux.

No AI coding assistant is required. ChangeReview reviews changes made by you,
your teammates, or an AI coding agent.

### Optional: GitHub Copilot for Eclipse

Install **GitHub Copilot for Eclipse** to have ChangeReview track its agent's
changes in [Time Machine](../basics/time-machine.md). Configure the integration
on the **Agent Review** preference page under the GitHub Copilot for Eclipse
preferences.

## Install

1. Open **Help > Eclipse Marketplace**.
2. Search for **ChangeReview** and click **Install**.
3. Follow the prompts, review and accept the license, and finish installation.
4. Restart Eclipse when prompted.

:::note Screenshot needed: Installation
Show Eclipse Marketplace search results for **ChangeReview**, with the product
name, icon, and **Install** button visible.
Suggested filename: **marketplace-install.png**.
:::

After restarting, look for **Show Changes** in the status bar. Open a file and
try [Live Review](../basics/editor-review).

## Updating

Open **Help > Check for Updates**, select an available ChangeReview update,
and follow the prompts. Restart Eclipse to complete the update.

## Uninstalling

Open **Help > About Eclipse IDE > Installation Details**. Select ChangeReview
on the **Installed Software** tab, click **Uninstall**, and follow the prompts.
Restart Eclipse when prompted.

Need assistance? See [Getting Help](../getting-help/getting-help.md).
