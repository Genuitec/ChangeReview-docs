you already use. ChangeReview shows added lines in green and deleted lines as
red gaps, with full syntax coloring.

## Live Review

See uncommitted changes directly in a text editor. Step through edits and use
change actions to review your work before committing.

![Live Review in Eclipse showing inline additions, deletions, and the floating change navigator.](/img/live-review.png)

[Use Live Review](./basics/editor-review.md)

## Inline Compare

Read an Eclipse comparison top to bottom in a single pane. Switch back to the
side-by-side view with the same command.

![Inline Compare in Eclipse showing a single-pane diff and the Side-by-Side button.](/img/inline-compare-small.png)

[Use Inline Compare](./basics/inline-compare.md)

## Time Machine

Browse a file's history on a timeline and inspect past versions with inline
changes. Exploring history leaves your editor buffer and file on disk untouched.

![Time Machine showing a selected historical version, inline changes, and the history timeline.](/img/time-machine.png)

[Use Time Machine](./basics/time-machine.md)

All three tools match your editor's theme and font and include a floating
navigator to move between changes.
